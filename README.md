⚡ ABOUT SRY-OSINT

SRY-OSINT is an Open Source Intelligence (OSINT) toolkit created by OFFICIAL_cyber_satyam27.

Designed for cybersecurity learners, ethical hackers, developers, and security researchers, SRY-OSINT aims to make publicly available information easier to investigate through a convenient terminal interface.

«🕵️ Collect knowledge. Analyze information. Protect the digital world.»

🔥 FEATURES

Features depend on the modules implemented in your project.

- 🌐 IP Intelligence — Inspect publicly available IP information.
- 🔎 Domain Investigation — Gather domain registration information.
- 🛰️ DNS Lookup — Inspect DNS records.
- 🌍 GeoIP Information — View approximate IP geolocation data.
- 📡 HTTP Header Analysis — Inspect web server response headers.
- 👤 Username Search — Search for publicly accessible username profiles.
- 📧 Email OSINT — Investigate publicly available email-related information.
- 📞 Phone Number Information — Retrieve permitted, publicly available number metadata.
- 🔗 URL Analysis — Inspect URLs and associated domain information.
- 🚪 Port & Service Checks — Test authorized systems for accessible network services.
- 🖥️ Terminal Interface — Designed for a command-line workflow.
- 🐧 Android & Linux Support — Intended for Termux and Linux environments.

🛠️ INSTALLATION

1. Update packages

pkg update && pkg upgrade -y

2. Install requirements

pkg install git python -y

3. Clone the repository

git clone https://github.com/OFFICIALcybersatyam27/SRY-OSINT27.git

4. Enter the project directory

cd SRY-OSINT27

5. Install Python dependencies

pip install -r requirements.txt

6. Run SRY-OSINT27

Check your repository for the correct entry-point filename.

python main.py

Important: Replace "main.py" with your actual Python filename if your project uses a different entry point. The GitHub repository URL and dependency file must also match your real repository.
